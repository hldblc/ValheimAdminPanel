# Advanced Admin Panel - English (source language)
#
# Format: key=value, one per line. '#' starts a comment. The FIRST '=' splits the pair,
# so values may contain '='. Use \n for a line break inside a value.
#
# {0}, {1} ... are substituted at runtime. Keep every placeholder that appears in the English
# line - you may REORDER them to suit your language, but dropping one loses information and
# adding an unknown one makes that line fall back to English.
#
# Leading/trailing spaces are trimmed, so you never need to preserve invisible padding.
#
# To translate: copy this file to <language code>.txt, translate the right-hand sides only,
# and leave the keys untouched. Drop it in BepInEx/plugins/AdminPanel_Localization/ to test
# without rebuilding the mod, then run tools\check-locales.ps1 to verify nothing drifted.
#
# NOTE: item, creature and status-effect NAMES are not here - they come from Valheim itself
# and always follow the game's own language setting.
