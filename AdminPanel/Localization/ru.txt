# Формат: ключ=значение, по одной паре на строку. '#' начинает комментарий. ПЕРВЫЙ '=' разделяет пару,
# поэтому значения могут содержать '='. Для переноса строки внутри значения используйте \n.
#
# {0}, {1} ... подставляются во время работы. Сохраняйте каждый заполнитель из английской
# строки - их можно ПЕРЕСТАВЛЯТЬ под свой язык, но пропуск заполнителя теряет информацию, а
# добавление неизвестного вернёт эту строку к английскому варианту.
#
# Пробелы в начале и в конце обрезаются, так что сохранять невидимые отступы не нужно.
#
# Чтобы перевести: скопируйте этот файл в <код языка>.txt, переведите только правые части
# и не трогайте ключи. Положите его в BepInEx/plugins/AdminPanel_Localization/ для проверки
# без пересборки мода, затем запустите tools\check-locales.ps1 и убедитесь, что ничего не разошлось.
#
